03 / Math / Algorithm Used

Math / Algorithm Used

Classification rule, not math A flat script is a deletable shim iff a canonical twin exists in integration/, reopt/, or pysam/ (its body is a thin runpy/sys.path redirect, ≤18 lines). Otherwise it is a real implementation and is moved, never deleted.

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • Plan premise was wrong: the plan called all ~37 flat scripts "shims." In reality 7 were real 115–404-line implementations with no canonical twin. Blindly deleting (as written) would have lost real code — caught by the twin-existence classification before any deletion.
  • Second-best alternative: leave the 7 reals at the flat level. Rejected — it would leave the messy mixed layer the sprint set out to eliminate; relocating to integration/ is safe because they resolve paths from the working directory, not __file__.
  • Limitation: Julia + Layer-4 solver tests not run here; the changes are Python file moves/deletes, validated by import-level test runs and compile checks.
