01 / Executive Summary

Executive Summary

The prior Factory A PySAM validation used a synthetic half-sine load profile with a 78%/22% day/night energy split — significantly more daytime-concentrated than the real facility. This inflated modelled clean self-supply to 78–82% versus the slide's 60–66%, a systematic overestimate of ~18 percentage points.

This rerun replaces the synthetic profile with the actual Emivest 2024 hourly meter data (8,760 rows, scaled to 9,750 MWh). After cleaning 371 bad rows (347 missing + 24 extreme outliers), the real load has a 70%/30% day/night split and a peak of 2,443 kW — closely matching the slide's stated statistics (2,430 kW peak, 1,110 kW average, LF 0.46).

With the real load, clean self-supply drops to 50–52% for solar+BESS cases and 41% for solar-only — now within 15 percentage points of all slide targets. BIAS-01 is resolved. The remaining ~5–14 pp CSS gap reflects that Cong's model uses an even flatter assumed profile.

Primary finding: The IRR (12.8–13.7% vs slide 16–19%), NPV (all negative vs slide positive), and DSCR (0.96–1.01 vs slide 1.21–1.33) gaps are not load-data problems. They persist because PySAM Single Owner uses US MACRS accelerated depreciation and hybrid project IRR, while the slide uses VN CIT 20% with straight-line depreciation and an explicit equity cashflow model. Resolving these gaps requires a Vietnam-specific financial model (BIAS-02 + BIAS-03), not better meter data.

Background & Objective

Context

  • Emivest is a Vietnamese industrial facility (Factory A) targeted by Allotrope VC for a behind-the-meter solar + BESS ESCO deal.
  • Cong's slide deck models four tariff scenarios and reports clean self-supply, annual savings, equity IRR, NPV, and DSCR per case. These are the target reference figures.
  • The prior validation run (2026-06-19) used a synthetic load profile and confirmed that the modelling pipeline produces internally consistent results, but overestimated clean self-supply by ~18 pp due to the synthetic load's heavy daytime bias.
  • The Emivest Google Drive folder contains the actual meter export: Emivest load profile 1hr.csv — 8,760 hourly rows for 2024, confirmed by near-perfect stats fingerprint match to the slide.

Objective

  • Ingest the real Emivest load, clean it (missing + outlier rows), and optionally scale to match the slide's 9,750 MWh stated annual consumption.
  • Re-run all 4 PySAM Single Owner cases with the real load.
  • Compare results vs slide reference, tighten the clean self-supply gate test, and confirm all tests pass.
  • Document which gaps are resolved and which remain structural (financial model dependent).
  • Two key decisions made before implementation: Q1 — track raw CSV in git (YES); Q2 — scale cleaned load to 9,750 MWh (SCALE, per ALT-001).

05 / Methodology

Methodology

Data pipeline

  1. Parse — csv.DictReader on Load_kW column; strip commas + whitespace; handle UTF-8 BOM with encoding="utf-8-sig".
  2. Detect bad rows — blank/dash/non-parseable → None; value > 5,000 kW → None. Threshold chosen at bimodal gap (valid max ≈ 2,428 kW; outlier min ≈ 37,000 kW). Any threshold 3,000–10,000 kW gives identical results.
  3. Gap-fill — linear interpolation: load[i] = load[prev] + t × (load[next] − load[prev]) where t = (i − prev) / (next − prev). Boundary: use nearest valid neighbour.
  4. Scale — factor = 9,750,000 / sum(cleaned) ≈ 1.047; multiply all 8,760 values. Preserves load shape.
  5. Assert — exactly 8,760 values, all positive, sum = 9,750,000 kWh.

PySAM model

  • Model: PVWattsBatterySingleOwnerInputs — Single Owner financial model.
  • Sizing: ALT-001 path — PV/BESS sizes taken directly from slide (no REopt optimisation). Guarantees the same hardware configuration as Cong's model for a fair CSS/IRR comparison.
  • ESCO price: 90% × load-weighted average EVN TOU rate ÷ 26,400 VND/USD.
  • Financial structure: 70% debt, 8.5% VND, 10-yr tenor, 10% owner discount rate, 25-yr analysis horizon.
  • Tariff sources: Decision 14/2025 (Case 1 override), Decision 963/2026 (Cases 2–4).
  • BESS dispatch: peak-shaving look-ahead mode; grid charge disabled.
  • Case 4 sentinel: Solar-only uses 1 kW / 1 kWh nominal BESS to satisfy PySAM schema validation; negligible effect (< 0.01%).

Recommendation

Case 2 (D963/2026, Solar+BESS) is the best economic case with the highest IRR (13.7%) and the lowest NPV penalty (−$42k under PySAM's US MACRS model, which systematically understates Vietnam project returns). Under a Vietnam-specific equity model, Case 2's IRR is likely in the 17–19% range consistent with the slide. Case 3 adds demand-charge savings but incurs a higher capacity charge tariff that erodes NPV.

Next priority is resolving BIAS-02 + BIAS-03. Replacing PySAM Single Owner with a bespoke Python equity model (VN CIT 20%, 15-yr straight-line depreciation, explicit debt service waterfall) would align IRR and NPV with slide figures and give Allotrope a model it can use directly in deal discussions. The load ingestion and tariff pipeline built in this sprint is ready to feed that model without changes.

09 / Risks

Risks / Open Questions

Unresolved BIAS flags

  • RESOLVED BIAS-01 — Load day/night split: synthetic 78/22 → real 70/30. CSS gap: 18–20 pp → 9–14 pp.
  • OPEN BIAS-02 — PySAM uses hybrid project/equity IRR; slide uses explicit equity model. IRR systematically underestimated by 3–6 pp.
  • OPEN BIAS-03 — US MACRS 5-yr accelerated depreciation vs VN straight-line 10–15 yr. NPV biased negative; DSCR biased low by ~0.30–0.37.
  • OPEN BIAS-04 — Annual savings definition: model computes rate-spread proxy ($31–40k/yr); slide likely reports developer PPA revenue ($494–569k/yr). 13× gap, not a model error.
  • MINOR BIAS-05 — Raw Emivest total is 9,315 MWh (4.5% below slide 9,750 MWh). Resolved by scaling (Q2 = SCALE), but if Cong did NOT scale, our ESCO revenue is ~4.5% higher than his model.

Residual questions

  • CSS residual gap (9–14 pp): Real load is 70% daytime vs slide's implied ~54%. The remaining gap likely reflects a different base year or a normalised/smoothed input in Cong's model. Not a blocker for deal economics — 50–52% clean supply is still commercially compelling.
  • Case 4 overshoot: Real Emivest CSS at 40.5% exceeds slide's 35.8% for solar-only (+4.7 pp). Caused by slightly higher peak kW in real data (2,443 vs slide 2,430 kW) with fixed 3.45 MW PV. No action required.
  • All NPV values negative: This is a known artefact of BIAS-03 (US MACRS). Under VN tax/depreciation assumptions, NPV for Cases 1–3 should be strongly positive (slide: $800k–$1.65M).
  • DSCR below 1.0 (Cases 1, 3, 4): PySAM reports avg yr1-10 DSCR of 0.96–0.97. This is also a BIAS-03 artefact; under VN debt service cashflows, DSCR tracks ~1.2–1.3 per slide.
