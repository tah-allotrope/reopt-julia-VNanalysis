06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • Synthetic generation profiles: Both evaluations use flat synthetic generation profiles (constant hourly output) rather than realistic 8760 solar/wind profiles. This overestimates matched energy and understates curtailment. Future: use GAP-01 ingestion or REopt-solved profiles.
  • No PySAM developer finance: Developer IRR/NPV fields are null — the procurement engine does not yet call the PySAM bridge. This is a planned extension.
  • Single strike point: Comparison uses a single strike per option. No sensitivity sweep is built into the comparison (though run_strike_sweep() from GAP-04 is available).
  • Second-best alternative: Hardcode saigon18-vs-ninhsim comparison without generalization. Not chosen because it doesn't scale for client demos with arbitrary factories.
