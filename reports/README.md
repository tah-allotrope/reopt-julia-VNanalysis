# Reports

Active deliverables live at top-level `reports/` (current sprint). Historical
phases are archived by month/initiative under `reports/archive/`.

## Layout

```
reports/
  2026-08-*.md/html          # active: August last-mile + generic deal path
  archive/
    2026-03/                 # north-thuan pipeline
    2026-04/                 # ninhsim + dppa case 1/2/3
    2026-05/                 # allotrope template + regime toggle
    2026-06/                 # samsung TTC + sprint trims + deck verification
    2026-07/                 # strategic lens + decree-243 + hygiene
    ceba/                    # CEBA deck review artifacts
    dppa-july-2026/          # dppa July 2026 sweeps/calibration/repo checks
  decks/                     # tracked deck binaries (conformance)
```

All `*.html` under `reports/` are frozen phase deliverables (tracked). Regenerable
run outputs remain gitignored under `artifacts/reports/` and `reports/decks/`.
