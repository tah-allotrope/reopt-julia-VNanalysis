03 / Math / Algorithm Used

Math / Algorithm Used

Phase 5 has no new math — it is a wiring + verification pass. The end-to-end flow is:

  1. Orchestrator (Phase 2): reads the registry, dispatches every Check.repo_fn, fills repo_value/delta_pct/verdict/takeaway, writes the JSON. Idempotent on re-run (only the generated_at_utc timestamp changes).
  2. Markdown synthesis (Phase 3): reads the JSON, groups by bucket, emits the colleague-friendly markdown with verdict counts, per-bucket tables, structural reconciliations, and known-gap callouts. Always re-runnable from the JSON — never hand-edited.
  3. Note injection (Phase 4): copies the source deck, writes a structured [Repo check] block into the speaker notes of every slide that has a registry check, idempotently. Source mtime preserved.
  4. Idempotency re-run (Phase 4 test): re-invokes the injector, re-reads Slides 12, 24, 26, and asserts sha256 byte-equality. This is the only validation that the idempotency contract holds across re-runs.

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • Idempotency is per-check, not per-deck. Two runs produce byte-stable notes for Slides 12, 24, 26 (the Phase 4 exit slides). All 24 annotated slides are byte-stable across runs by the same construction (the replace function uses the delimiter + check id as a deterministic key). A full-deck sha256 sweep could prove this for all 24 slides; not done here because the exit criterion is 3 representative slides.
  • The pptx is a 12.96 MB untracked binary. This is intentional (DEC-009: large file, git-ignored, handed off to colleagues on disk) but it does mean "git status" shows it as untracked forever. If the colleague loses their copy, the pipeline can re-generate it in < 1 second from the source.
  • The PySAM null IRR finding is the most important unmodeled assumption in the deck. The deck's Case 5 / Case 6 metrics (16.9% / 26.9% seller equity IRR; 1.14× / 1.50× min DSCR) cannot be reproduced from the deck's stated inputs (49 MWp, 70% debt / 8.5% / 10-yr, strike 2,000 VND/kWh, 25-yr). The deck's figures require undisclosed assumptions. This is in the deck note (Slide 24) and the markdown structural reconciliations, but a colleague may need to ask the deck author directly which inputs close the gap.
