Factory A BESS Slide Validation

Validated Cong's CEBA BESS session slide deck (Factory A, southern Vietnam manufacturing) against the repo's PySAM Single Owner pipeline. Four cases — Decision 14 legacy TOU, Decision 963 current TOU, Decree 146 two-part capacity charge, and solar-only — were modeled at fixed slide sizes. PySAM reproduces relative ordering of cases correctly; absolute IRR and NPV systematically understate the slide due to four documented model biases. 14 gate tests pass. 03 / Math / Algorithm

Math / Algorithm Used

ComponentFormula / MethodNote
Synthetic load w(h) = 0.055 + 0.945 × sin(π × (h−6)/16) for 6 ≤ h < 22; w = 0.055 at night. Sunday dip 0.90×. Scale so ∑w × k = 9,750,000 kWh. Achieves total, peak, LF constraints. Cannot simultaneously satisfy slide's 54%/46% day/night split — documented as BIAS-01.
Load-weighted avg TOU rate LW = ∑(load[h] × rate[h]) / ∑load[h] over 8,760 h. D963: 2,231.59 VND/kWh; D14: 2,305.46 VND/kWh. Determines ESCO PPA price = 90% × LW / 26,400 USD/kWh.
ESCO price P_esco = 0.90 × LW_vnd / FX where FX = 26,400 VND/USD. D963: $0.07608/kWh; D14: $0.07860/kWh. Input to PySAM PPA price.
Clean self-supply % CSS = annual_matched_load_kwh / total_load_kwh × 100. Matched = min(solar+BESS dispatch, load) hour-by-hour. PySAM tracks grid-to-load and batt-to-load vs load. Clean = 1 − grid_fraction.
Avg DSCR (yr 1–10) avgDSCR = mean(cf_pretax_dscr[1..10]) from PySAM Single Owner annual cashflows array. Debt period = 10 yr. Years after debt is paid have infinite DSCR and are excluded.
Equity IRR PySAM cf_pretax_cashflow → IRR using project-level cashflows with equity portion as initial outflow. Hybrid proxy (see BIAS-02). Systematically underestimates dedicated equity IRR. Reported as-is with bias note.
Case 3 demand-charge savings Monthly peak grid import = max(grid_to_load[h]) per calendar month. Savings = ∑m(BAU_peak_m − post_solar_peak_m) × rate_per_kW/month. Post-processed outside PySAM. Run at both slide rate (209,459 VND/kW/mo) and repo medium-voltage rate (235,414 VND/kW/mo).
Tariff TOU series 8,760-point lookup from weekday/holiday schedule × rate multipliers. Peak 1.57, standard 0.86, offpeak 0.56 × base 2,204 VND/kWh. D14 uses hardcoded legacy schedule override; D963 uses live regime registry schedule.

06 / Limitations

Limitations / Second-Best Alternative

BIAS-01 — Load profile day/night split
Synthetic profile has 78%/22% day/night energy split vs slide's ~54%/46%. A smooth half-sine cannot simultaneously satisfy avg=1,113 kW, peak=2,430 kW, LF=0.46, and the 54/46 split (mathematically impossible with a single-peak diurnal shape). Clean self-supply is therefore 15–20 pp higher in PySAM because PV more easily serves the daytime-concentrated load.
BIAS-02 — Hybrid IRR computation
PySAM Single Owner equity_irr derives from project-level cashflows but uses only equity as the initial outflow. This is a hybrid project/equity IRR that underestimates a correct dedicated equity model. The slide likely uses a standalone equity waterfall with Vietnamese CIT treatment.
BIAS-03 — Tax / depreciation regime
PySAM defaults to US MACRS 5-year accelerated depreciation and ~5.75% combined federal+state tax rate. Vietnam uses CIT 20% with straight-line depreciation over the asset life. The two effects partially offset but do not cancel; the net impact on IRR is directionally negative vs a Vietnam-correct model.
BIAS-04 — Annual savings definition
Slide's "annual savings" (~$531k for Case 1) is consistent with developer PPA revenue (matched_kWh × ESCO_price ≈ $600k at 78% CSS), not customer bill savings (which would be ~$50–70k/yr at 10% margin on matched energy). The exact definition was not confirmed with Cong.

Second-best alternative (ALT-001 rationale)

The plan originally called for REopt Julia to independently optimize sizing. REopt is not available in this environment, so ALT-001 was applied: use the slide's own PV and BESS sizes as fixed inputs to PySAM. This means sizing metrics (PV MW, BESS power/capacity) always pass trivially (WIDE ±25% tolerance, values are identical). The meaningful validation is therefore limited to financial and energy metrics: IRR, DSCR, clean self-supply, NPV.

The most valuable remediation would be: (1) obtain a real Factory A load file from Cong to eliminate BIAS-01, and (2) replace PySAM Single Owner with a Vietnam-specific equity model (CIT 20%, straight-line depreciation, local debt terms) to close BIAS-02 and BIAS-03.

08 / Open Questions

Open Questions / Next Phase Seeds

  • Real Factory A load file from Cong. The slide's ~54%/46% day/night split is physically plausible for a factory with significant HVAC and 24/7 process loads, but it cannot be reproduced synthetically. A real 8,760-point meter file would eliminate BIAS-01 and bring clean self-supply into range of the slide.
  • Annual savings metric definition. Does the slide's "$531k savings" refer to (a) developer PPA revenue, (b) customer bill reduction, or (c) something else? Reconcile with Cong. If developer revenue: PySAM proxy matches within ~10%. If customer bill savings: $50–70k/yr from repo vs $531k on slide — a 10× gap.
  • Vietnam-specific financial model. Replace PySAM Single Owner with a Vietnam CIT 20% + straight-line depreciation equity model. The current hybrid IRR proxy consistently underestimates by ~3–4 pp. A correct Vietnam equity waterfall would close BIAS-02 and BIAS-03 simultaneously.
  • Decision 963 capacity charge rate. The slide uses 209,459 VND/kW/month (≥110 kV rate from Decree 146). The repo uses 235,414 VND/kW/month (22–110 kV medium voltage). Confirm Factory A's actual connection voltage class.
  • REopt Julia sizing validation. All sizing figures in this study were taken from the slide (ALT-001). An independent REopt optimization run would test whether the optimizer independently arrives at similar PV/BESS sizes, which is the strongest possible validation of the slide's conclusions.
  • Case 1 tariff regime confirmation. Case 1 was modeled with Decision 14/2025 legacy TOU (split morning+evening peak) based on the user's answer that it represents "a new TOU released in the past 1–2 months in Vietnam." This interpretation correctly differentiates Case 1 from Case 2 and explains the smaller BESS sizing (morning PV captures morning peak). Confirm this interpretation is Cong's intent.
