03 / Math / Algorithm Used

Math / Algorithm Used

No math in this phase Pure git index manipulation. The only rule of note is gitignore precedence: a later negation (!reports/*sprint-1*.html) re-includes files an earlier glob (reports/*.html) excluded, because the parent reports/ dir is not itself ignored.

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • Limitation: Git history still carries every large blob, so git clone size is unchanged until/unless history is rewritten (out of scope; noted for a future filter-repo pass).
  • Effect realized now: future growth stops, the working tree is clean, and diffs no longer churn on generated output.
  • Second-best alternative: delete artifacts/ from disk entirely. Rejected — ~50 report scripts write there and some read prior outputs; deletion would break them.
