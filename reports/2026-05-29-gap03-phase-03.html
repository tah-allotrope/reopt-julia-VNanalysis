03 / Math / Algorithm Used

Math / Algorithm Used

PHASE-03 adds no new scoring math; it wires the PHASE-02 engine to real files. Ingestion normalizes any source to an 8760 hourly series (with sub-hourly / monthly synthesis where needed); the FactoryProfile derives annual consumption (Σ loads) and peak demand (max load). The artifact ranks matches by overall score and reports viable_count (matches with no BLOCKER flag and overall ≥ 50).

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • RISK-03-01: raw files may need a --column hint; the CLI accepts both raw files and pre-ingested artifacts via the GAP-01 loader.
  • Region, voltage, baseline cost, and co-location are CLI-supplied (not auto-derived from the load file) — a future site-data service would resolve these from coordinates.
  • The default run blocks onsite projects (no co-location assumed); the demo must pass --colocated-project-id to surface a co-located private-wire project.
