03 / Math / Algorithm Used

Math / Algorithm Used

Parity comparator semantics:

  • dict: key sets must match; recurse. list: length + element-wise recurse.
  • bool: exact (guarded before the numeric branch, since bool ⊂ int).
  • number: |a−b|/|b| ≤ 0.5% OR |a−b| ≤ 1e-6 (DEC-002 bar). The bit-exact test additionally asserts the global max relative diff is exactly 0.0.
  • other: exact equality (strings, sources, captions).

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • Why bit-exact, not just ≤0.5%: the generalized front door routes to the same builder on the same cached PVWatts resource, so determinism gives exact reproduction. The ≤0.5% bar exists for portability (a different solver/resource build) and is the documented gate; reality beat it.
  • Limitation: parity is proven for Samsung-TTC only (the richest, most recent golden). The other case modules (ninhsim, dppa_case_1/2/3) are not yet parity-gated against the generalized pipeline — they keep their own tests and are wrapped, not rewritten, in PHASE-05.
  • Second-best alternative: a loose ≤0.5%-only gate. Rejected — the bit-exact test is a stronger, cheap regression tripwire.
