# Plans

- Put current planning documents in `plans/active/`.
- Move superseded or historical plans into `plans/archive/`.
- Keep one canonical editable copy of each live plan; if an older path must remain for compatibility, leave only a short pointer note there.
- Keep `docs/worklog/research/` for research notes, not active implementation plans.
