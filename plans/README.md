# Plans

- Put current planning documents in `plans/active/` (long-lived roadmaps) **or** as `plans/2026-08-*.md` at top level for the current sprint (recent, e.g. last 2 sprints).
- Move superseded or historical plans into `plans/archive/` once the sprint is complete.
- Keep one canonical editable copy of each live plan; if an older path must remain for compatibility, leave only a short pointer note there (the `plans/pysam_integration_reorg_plan.md` pointer was removed 2026-08-30 — canonical is `plans/active/pysam_integration_reorg_plan.md`).
- Keep `docs/worklog/research/` for research notes, not active implementation plans.
- `plans/archive/` holds frozen historical plans; `reports/archive/` mirrors that for deliverables.
